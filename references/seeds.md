# Seeds

## Reference seeds

Data every environment needs to work: currencies, countries, statuses, default roles/permissions, chart-of-accounts templates.

- Location: `database/seeds/NNN-<table>.sql`, one file per table, numeric prefixes for dependency order.
- Included in `bootstrap.sql` (step 8) and verified by `database/checks.sql` (step 10).
- **Idempotent**: `INSERT … ON CONFLICT (natural_key) DO NOTHING` (or `DO UPDATE` when the file must win).
- **Fixed identifiers**: seed by natural key (`code`); never hard-code generated identity values. When another seed needs the FK, look it up: `(SELECT id FROM public.account_types WHERE code = 'asset')`.
- **No secrets, no personal data, no tenant data.**
- Changes to reference data in an existing database go through a migration, like any schema change, and the seed file is updated in the same commit.

Integrity check example (`checks.sql`):

```sql
IF (SELECT count(*) FROM public.currencies WHERE code IN ('EUR', 'USD')) <> 2 THEN
  RAISE EXCEPTION 'integrity: currencies seed incomplete';
END IF;
```

## The dev seed

One optional file, `database/seeds/dev.sql`, with mock data for local development and tests. Offered at scaffolding; generated or regenerated by `/sql-architect devseed`.

- **Not in the bootstrap.** Loaded by `docker-compose.dev.yml` on a fresh volume, or run with psql.
- **Refuses outside dev**: reads `APP_ENV` with `\getenv` and raises unless it is `development`, `local` or `test`.
- **Deterministic**: the same data on every run, so bugs reproduce. Ids via `md5('<entity>-' || n)::uuid`; values via `generate_series` and arithmetic on `n`, or `setseed()` before `random()`.
- **Idempotent**: `ON CONFLICT (id) DO NOTHING`.
- **Runs as a superuser** (inserts across tenants without being filtered by RLS) inside one transaction.
- **Respects the model**: inserts in FK order, satisfies checks, gives each tenant its own data so RLS can be tested.
- Volume is parametrizable (`\set n 100` at the top) and dates are relative to a fixed anchor (`DATE '2026-01-01' + n`) rather than `now()`, so they don't drift between runs.

See `references/commands/devseed.md` for the generation procedure.
